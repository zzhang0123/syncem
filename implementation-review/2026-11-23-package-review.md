# SyncEM 代码与文档审查

审查对象是 2026-11-23 的 `feat/0.8` 工作树，HEAD 为 `b24fe003b96b`，包内版本为 `0.9.0`。审查包括未提交和未跟踪的实现与文档。判断依据为当前公共入口、0.8 和 0.9 的 SPEC、实际构建产物以及下列数值复现。旧接口另与 `v0.7.10` 本地标签比较。

**建议暂缓发布当前工作树。** 正常调用可以在不报错的情况下丢失电子柱密度、套用错误通带或忽略新相位。三者都会改变最终 Stokes 谱。以下 P1 应优先处理。P2 给出影响范围较窄的运行、诊断或交付缺陷。

## P1 科学结果与模型选择

| 编号 | 触发条件与实测结果 | 修复与验收 |
| --- | --- | --- |
| 1. 谐波预测丢失源的总权重 | 用现有双原子样本、`HarmonicKernel(m_max=10)` 和单参考点基，计算 `se.predict(k * se.Population(samples), channels, basis=b)`。取 `k=0,1,3`，三次都得到 I = 1.48542568 × 10⁻²⁴，零阶矩都为 1。提取 `Samples` 时丢了外层 `column_factor`，直接参照也用了同一个错误振幅。[实现](../syncem/front/_harmonic.py#L85) · [原测试样本](../tests/v080/test_v080_single_reference.py#L229) | 在矩配对和直接积分两处传递完整物理柱密度。用零柱密度和三倍柱密度分别核验矩、绝对 Stokes 和直接参照。这一复现针对单参考点谐波桥。 |
| 2. 导入的谐波基复用了另一条通带的行 | 两条表格通带有相同的单点求积节点、权重和面积，但两翼透射率不同。相同的旧版谐波基构造、相同的单位零阶矩，第二条通带独立建基给 I = 1.63428948 × 10⁻²⁴。请求第二条通带并复用第一条基，得到 1.45794629 × 10⁻²⁴，低 10.8%，结果上还保留第一条通带。顶层入口和桥接类都只比较求积行键。[顶层判断](../syncem/front/__init__.py#L285) · [桥接类](../syncem/engine/single_reference.py#L78) | 使用能识别谱线频率处透射率的通带标识。项目的双分支实现已有此逻辑。存储基无法重算时应拒绝新通带。测试同时比较数值和返回的通带。[已有响应判断](../syncem/engine/_regime_columns.py#L79) |
| 3. 预建基会忽略显式传入的相位或核 | 在普通 `SpectralBasis` 上显式增加深度为 8 rad/m² 的屏，1 GHz 时仍得 (Q, U) = (−5.518 × 10⁻²⁹, 0)。按该相位重新建基得到 (−7.306 × 10⁻³⁰, −5.469 × 10⁻²⁹)。读回的 NPZ 和内存基均可复现。拟合也接受互相冲突的核。三条 I = 10、σ = 1 的观测，旧核恒为 1，新核恒为 10，同时传旧基和新核得到固定模型 χ²=243，重新建基则为 0。自由拟合给出的柱密度分别为 10 和 1。[预测](../syncem/front/__init__.py#L260) · [自由拟合](../syncem/front/_inverse.py#L52) · [固定模型拟合](../syncem/front/_separable.py#L102) | 在公共入口统一核验显式模型声明和预建基。冲突时报告需要重建的核或相位。覆盖前向、固定模型、自由矩和存档重载。 |
| 4. 宽频带连续谱的直接积分会误用小 x 渐近式 | 两个通道 0.01、1.4 GHz，5 μG、`eta=0`、`mu=Isotropic()`、`gamma=Delta(10000)`，能量格子覆盖 300–2000。高频 `basis.direct(p).I` 为 3.76880 × 10⁻³²。直接在同一物理点调用 `ContinuumKernel(x_min=1e-8).channel` 得 7.48687 × 10⁻²⁹。SPEC 要求用最低频率决定统一的能量阈值，使高频节点也提前进入渐近区。这个反例衡量同一连续谱模型对格外单原子的直接积分误差，论文预设和格内预测的误差需要另行测量。[阈值与缩放](../syncem/engine/direct.py#L46) · [设计规定](../design/0.8/SPEC.md#L1269) | 按频率节点和局部横向磁场的实际 x 决定能否使用渐近式，并在 SPEC 中更新调度条件。用宽频带的最低及最高通道分开与核对照。当预算允许执行直接对照时，`predict(check=True)` 会把触及尾部的 `small_x:tail` 列为 unbounded。单独调用 `direct` 没有加入这项说明。[预测账本](../syncem/front/_predictions.py#L336) · [直接积分账本](../syncem/front/_direct.py#L176) |
| 5. 相对误差声明可以产生绝对零误差上界 | 从一个含绝对 Stokes 未定项的 `Ledger` 出发，通过 `allow` 传入 `ErrorTerm(0.3, "bound", relative_to="I")`。随后 `unbounded()` 为空，`envelope()` 返回数值 0、类型 `bound`、声明列表为空。传 `space="retained"` 同样可复现。替换操作未核对误差所在空间，而求和只选绝对 Stokes 项。[声明替换](../syncem/records/ledger.py#L253) · [上界汇总](../syncem/records/ledger.py#L244) | 检查被替换项和新声明的空间与参考量。缺少把相对误差转换为 Stokes 单位的参考强度时，保留绝对误差未定状态。测试应直接检验最终 envelope。 |
| 6. 旧版冷等离子体转换率对整数频率给出错误符号 | `mueller_conversion(jnp.asarray(1_000_000_000), 1., 5e-6)` 返回 +2.38773 × 10⁻¹⁹ cm⁻¹，同值浮点频率返回 −1.65491 × 10⁻²⁷ cm⁻¹。整数的三次幂在除法前溢出。旋转率中的平方在 5 GHz 的 int64 输入上也会溢出。该文件与 `v0.7.10` 一致。[转换和旋转系数](../syncem/conversion.py#L28) | 在求幂前提升到浮点。对 JAX 整数数组、浮点数组及 JIT 路径使用同一有符号数值参考。 |

在第 2 项中，两条表格通带使用频率网格 139962.44936166518 × [1, 1.5, 2, 2.5, 3] Hz，透射率分别为 `[0,.8,1,.2,0]` 和倒序，`n_nu=1`。这组最小输入专门区分通带积分与在离散谱线上读取透射率两种操作。

## P2 旧版低层核的数值范围

两项涉及的文件与 `v0.7.10` 相同。修订时需考虑仓库对旧接口的兼容承诺，并针对受影响的输入说明版本边界。

- **高斯屏可对整数波长产生偏振放大。** 波长 `jnp.int32(216)` 米、平均 RM 为 0、方差为 10⁻¹⁰、入射偏振模长为 1。得到模长 1.527507，浮点参考为 0.647034。应在波长的四次幂之前转换类型，并检验非负方差时衰减因子不超过 1。[高斯屏](../syncem/rm.py#L133)
- **视线轴附近的高能谐波强度受消去误差影响。** n = 1、γ = 10⁸、α = 10⁻⁹、θ = 0、B = 1 G 时，`stokes_harmonic` 给 0.0138434，高精度轴上解析式给 0.147096。取 γ = 2 × 10⁸ 时函数返回 NaN，参考为 2.15568。这些输入满足 docstring 的取值范围。建议使用稳定的 Doppler 分母及分子表达式，并在轴上解析极限处验收。[计算](../syncem/stokes.py#L48) · [参数范围](../syncem/stokes.py#L72)

## 发行与文档

- **P2 · 源码发行包缺六个回归基准。** 从当前代码重新构建 sdist 和 wheel。wheel 包含全部包内 Python 源文件。sdist 缺少 `tests/v080/data` 中两个 jet 和四个 stack NPZ。解包后运行 jet 的参考摘要测试及 stack 的参数化摘要测试，三项均因 `FileNotFoundError` 失败。README 明确指导源码包用户运行整个测试目录。发布工作流的选测未覆盖这两个测试。应把六个文件列入 MANIFEST，并在解包后的 CI 中运行校验。[MANIFEST](../MANIFEST.in#L7) · [发布检查](../.github/workflows/publish.yml#L79) · [安装说明](../README.md#L135)
- **P2 · README 缺少两代公共接口的入口和归一化对照。** PyPI 使用仓库 README 作为包说明。读者在其中找不到 `se.spectral_basis`、`se.paper.regime_basis` 以及新版矩的约定。两份新指南已从 Sphinx 首页链接。建议在 README 开头用短例引到两份指南，并说明 `syncem.model` 的归一化矩和独立振幅，以及新层的物理柱密度和通带归一化。这也是已接受的设计决定。[README](../README.md#L22) · [矩格点指南](../docs/guide/moment_lattice.md#L65) · [双分支指南](../docs/guide/two_regime.md#L1) · [决议 12](../design/0.8/SPEC.md#L2113)
